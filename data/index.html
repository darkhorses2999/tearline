Moonshot · how the data engine works

Can a backtest lie to you?

Yes — and most do. We built the machine so ours can't.

Free market data goes in, an honest verdict comes out. The whole thing on one screen — tap any step to go deeper.

The machine · five plain steps
01GatherPull free daily prices — Yahoo Finance, Binance.
One adapter per source behind a single shape, so if one free feed dies the loop fails over instead of breaking.borrowed from OpenBB · ccxt
02LockFreeze each day's data so it can never be quietly changed later.
Exchanges silently restate old prices. If we re-pulled and overwrote, yesterday's "fact" could change under us — and a backtest would cheat without anyone noticing. So every pull is saved once, stamped, and never edited.borrowed from zipline bundles
03CleanThrow out broken rows — loudly, not silently.
Negative prices, gaps, impossible highs — caught the moment data arrives, and the run stops, instead of poisoning a result you'd trust by mistake.borrowed from Pandera checks
04ReplayWalk through history one day at a time — blind to tomorrow — and trade.
The same code runs the backtest, the paper-trade, and one day the real account. Costs and taxes come out of every trade. This is where the one rule below lives.borrowed from Lean · Nautilus
05GradeThe live market scores it. Our own backtest gets no vote.
A pretty backtest curve is a hypothesis, not a result. Only money moving forward, through a real unseen future, counts as a pass.the honest floor — the market is the judge
The one rule that keeps it honest

No peeking at the future.

Every decision can use only days that already happened. Tomorrow isn't "off-limits" — it physically isn't there to read.

A leaky backtest peeks at Friday → looks like genius → loses real money the moment it's live.
