01

The machine

Data flows top to bottom through five stages. Each does a single job — and the loop only matters because of the one rule it enforces near the end.

data flow where “no peeking” is enforced
1 Gatherpull free daily prices

One adapter per source behind a single shape, so if one free feed dies the loop fails over instead of breaking.

borrowsOpenBBccxt
2 Lockfreeze each day so it can’t change later

Exchanges silently restate old prices. If we re-pulled and overwrote, yesterday’s “fact” could change under us and a backtest would cheat unnoticed. So every pull is saved once, stamped, never edited.

borrowszipline bundles
3 Cleanthrow out broken rows loudly

Negative prices, gaps, impossible highs are caught the moment data arrives and the run stops — instead of poisoning a result you’d trust.

borrowsPandera checks
4 Replaywalk history one day at a time, and trade

The same code runs backtest, paper-trade and (one day) the real account; costs and taxes come out of every trade. This is where the one rule lives.

borrowsLeanNautilus
5 Gradethe live market scores it — not us

Our own backtest gets no vote. Only money moving forward through a real, unseen future counts as a pass. The honest floor.

the external grader · the market itself
02 · the teaching centerpiece

No peeking at the future.

Every decision can use only days that already happened. Tomorrow isn’t off-limits — it physically isn’t there to read.

A leaky backtest

Peeks at Friday

Uses data it could never have had in real life.

looks like genius → loses real money

… the moment it goes live.

Ours

Blind to Friday

Can only ever see Mon–Thu, exactly like a real trader.

looks modest → but if it wins, it’s real

… because nothing was faked.
