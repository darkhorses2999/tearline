The honest-backtest machine

Can a backtest lie to you? Yes — and most do. We built the machine so ours can't.

Free market data goes in. An honest verdict comes out. The trick that makes it honest: the machine physically can't see the future.

FREE DATA → THE MACHINE → HONEST VERDICT

The machine — five steps

raw free prices → a verdict you can trust

step01

Gather

Pull free daily prices — Yahoo Finance, Binance.

One adapter per source behind a single shape, so if one free feed dies the loop fails over instead of breaking.

borrowsOpenBB · ccxt
step02

Lock

Freeze each day's data so it can never be quietly changed.

Exchanges silently restate old prices. Every pull is saved once, stamped, never edited — so yesterday's fact can't shift under us.

borrowszipline bundles
step03

Clean

Throw out broken rows loudly, not silently.

Negative prices, gaps, impossible highs are caught the moment data arrives and the run stops — instead of poisoning a result you'd trust.

borrowsPandera checks
step04

Replay

Walk history one day at a time, blind to tomorrow, and trade.

The same code runs backtest, paper-trade, and the real account. Costs and taxes come out of every trade. This is where the one rule lives.

borrowsLean · Nautilus
step · the honest floor05

Grade

The live market scores it. Our own backtest gets no vote.

Only money moving forward through a real, unseen future counts as a pass. A green number on our own history is a hypothesis — not a result.

the one rule · teaching centerpiece★

No peeking at the future.

Every decision can use only days that already happened. Tomorrow isn't off-limits — it physically isn't there to read.
